Once downloading all the files, click on .env.example (with notepad) and read the instructions within.
Navigate to the free API website ->
Find the key logo in the bottom left ->
Click it and create your API key ->
Place API key into .env.example just after the "GEMINI_API_KEY="
Change file name from .env.example to .env
Your API key is installed!
Now go to powershell and navigate to the path with my github files ->
Type .\.venv\Scripts\python.exe -m app.main
Now you can use the given port in the terminal to access the browser demo
Whenever you are done, use CTRL + C to stop the server
