Official Portal File Format & Evidence Guidelines

HTML5 & AI Verified Formats

HostelKaki enforces strict file validation to assist facility contractors and warden triage. Please adhere to accepted file formats:

📷 Photo File Formats (Required)

.JPG, .JPEG, .PNG, .WEBP, .HEIC
Max size 10MB. High-contrast photo of physical damage.

🎥 Video File Formats (Optional)

.MP4, .WEBM, .MOV
Max size 20MB (10–30s). Visual proof for dripping, sparks, humming noise.

📄 Receipt & Export Formats

.HTML, .JSON, .PDF
